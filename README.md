# Telegram → TickTick

Переносимый шаблон навыка для настройки помощника Codex на Windows: чтение выбранных переписок Telegram и работа с задачами TickTick. Настройте собственные аккаунты, источники и разрешения.

## Установка с помощью Codex

На новом компьютере откройте Codex и попросите:

> Установи навык telegram-ticktick-assistant из папки skill этого репозитория и настрой перенос задач из моего Telegram в мой TickTick. Помоги подключить Telegram через QR, настрой расписание и повтор незавершённых проходов. Проверь сначала чтение, а потом одну согласованную запись в TickTick.

Укажите ссылку на этот репозиторий. Codex поможет настроить аккаунты и источники. Используйте собственные Telegram API ID и hash; не передавайте никому файл сессии, токены и пароли.

Навык находится в папке [skill](skill/), техническое руководство — в [skill/references/setup.md](skill/references/setup.md).

Шаблон повторяет незавершённые проходы и проверяет известные очереди. На новом компьютере необходимо проверить его на тестовых данных и убедиться, что реальные изменения появились в TickTick. Шаблон не гарантирует полноту анализа и не исправляет недоступность сервисов или прав доступа.
